# 🚀 Projeto TEXPAND - Controle Financeiro para Micronegócios

Repositório oficial da organização acadêmica do projeto **TEXPAND**, desenvolvido para a disciplina de Análise e Desenvolvimento de Sistemas da **Fatec Guarulhos**
## 💡 Sobre o Projeto
O **TEXPAND** é um sistema projetado para centralizar e simplificar a gestão financeira de micro e pequenas empresas (com foco inicial no setor de vestuário e varejo).

O grande diferencial do sistema é a **centralização de informações de vendas de diferentes plataformas de e-commerce e canais de venda** em um só lugar, permitindo que o microempreendedor tenha uma visão real e unificada da saúde financeira do seu negócio.

### 🎯 Principais Funcionalidades
* **Centralização de Plataformas:** Consolidação das movimentações de vendas, comissões, taxas e repasses vindas de diferentes canais de venda.
* **Fluxo de Caixa:** Registro e acompanhamento detalhado de todas as entradas e saídas financeiras.
* **Dashboard Interativo:** Visualização unificada com gráficos de receitas, despesas, saldo atual e filtros dinâmicos por período, categoria e forma de pagamento.
* **Gestão de Registros:** Controle completo de transações com acompanhamento de status (*Concluído, Pendente, Cancelado*).
* **Exportação de Relatórios:** Geração e extração facilitada de dados analíticos consolidados.
